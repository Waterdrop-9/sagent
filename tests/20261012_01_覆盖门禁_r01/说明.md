实验覆盖：

- confirmed sink 的每个敏感参数都必须有实际查询；查询使用解析后的外部函数地址时可以和函数模型匹配；
- Agent 自报的 `pathToolResult` 不会创建本地查询记录；
- `unknown`、无原因的工具失败、预算耗尽、未解析攻击面和 unresolved 会阻止 `canFinish`；
- 同一个地址位于不同 `binaryID` 时不会合并；函数模型序列化后可恢复；
- 工具代理只保存有界 JSONL 和 `evidenceID`，恢复前比较分析组身份，损坏记录不会静默跳过；
- CWE-78 prompt 不加载 PoC 文件。

真实 ELF 联调使用 `data/01_simple_demo/server`、显式依赖根和 OpenCode + GhidraMCP + paths。工具原始响应保存于本地运行目录，不提交到仓库；本次结果包含 3 条 paths 查询，最终因未知攻击面、未加载依赖、跨函数覆盖不足和 candidate/unresolved 保留为 `inconclusive`。
