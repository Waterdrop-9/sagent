# 20261015_01 预算与截断回归（PR 修复项）

## 目的

本 PR 修复四类"静默失效"缺陷，本目录只放**不依赖 angr / Ghidra / 网络**的单元回归，
每条断言直接对应一个曾被低估的行为：

| 测试文件 | 修复项 | 旧行为 |
|---|---|---|
| `test_chain_summary_budget.py` | `src/agent/cli.py::_chains_summary_payload` | `len(text.encode())` 判预算却用 `text[:BUDGET]` 按字符切片：中文实际字节可达预算数倍，且序列化 JSON 被切成无法解析的文本 |
| `test_resume_truncation.py` | `src/agent/artifacts.py::_summarize_fields` | 恢复摘要对 `unresolved/blockers/findings/functionModels` 静默 `[:16]`，"未展示"与"不存在"无法区分 |
| `test_hop_key_addresses.py` | `src/agent/risk_chains.py::_hop_key` | hop 只按 `(from, to, kind)` 函数名做键：同名函数的不同调用点会被精确去重合并 |
| `test_path_query_deadline.py` | `src/agent/path_query.py::AngrPathBackend._run_with_deadline` | `ReachingDefinitions` 无迭代/时间预算，`max_depth`/`max_nodes` 只约束 `_walk_definitions`，实测在 lrzip 上可挂死 >431s |

## 运行

```bash
PYTHONPATH=src python3 -m unittest discover -s tests/20261015_01_预算与截断回归_r01 -t tests/20261015_01_预算与截断回归_r01 -p 'test_*.py'
```

预期：`Ran 13 tests ... OK`（本机 Python 3.12.3；无 angr 依赖）。

## 兼容性说明

1. `hops` 新增 `fromAddress`/`toAddress` 字段，并进入 `_hop_key`：链 ID 与去重结果会变化，
   这是修复目标（旧行为把不同调用点视为同一条链）；无地址的历史产物回退到函数名，仍可比。
2. 恢复摘要新增可选的 `truncatedFields`/`note` 字段，原有数组字段与字段名不变。
3. `AngrPathBackend` 新增构造参数 `deadline_seconds`（默认 60s）；超时按 `limitations` 降级，
   不再阻塞调用方；RDA 线程为守护线程，超时后可能仍在后台运行（已在 docstring 说明）。
4. `Project`/`CFG` 按 `(路径, mtime, 大小)` 在进程内缓存，同一二进制多调用点不再重复建图。
