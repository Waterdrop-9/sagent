# 依赖检索与分析组构建

状态：设计稿 v0。输入范围和分组方式已确认，具体解析库和开发语言尚未选择。

## 目标

接收单个 ELF 或 rootfs 目录，在允许的范围内查找依赖。每个根 ELF 与它的递归依赖构成一个分析组，供后续 Ghidra 和 CWE 分析使用。

本模块只读取文件，不执行样本，不使用宿主机系统库，不处理固件解包和压缩包。

## 输入规则

| 输入 | 工作根目录 | 根目标和依赖搜索范围 |
| --- | --- | --- |
| 单个 ELF | 无默认工作根目录 | 仅显式指定的依赖目录或 sysroot |
| rootfs 或普通目录 | 输入目录本身 | 输入目录及显式指定的依赖目录或 sysroot |

单 ELF 不扫描父目录。没有依赖来源时，仍读取依赖声明，找不到的库记录为缺失。

rootfs 或普通目录是默认工作根目录。系统在其中递归发现 ELF、共享库和符号链接，自动识别各个程序并分别建组。共享库按依赖关系进入对应组，未被引用的库保留在候选清单中。目录没有可识别程序时返回明确状态，不擅自选择一个库作为根目标。

## 处理流程

```text
读取输入
  → 递归发现 ELF，建立候选索引
  → 识别根目标
  → 读取各根目标的 DT_NEEDED
  → 匹配依赖文件
  → 递归处理依赖自身的 DT_NEEDED
  → 输出分析组、依赖边和未解析记录
```

工作根目录和额外依赖来源只索引一次，各组复用索引。递归依赖处理使用已访问记录，避免重复读取和循环依赖造成无限遍历。

## 候选发现与根目标识别

按 ELF 内容识别文件，不能只搜索 `.so` 后缀。版本库名、无后缀文件和符号链接都需要保留。工作根目录中的所有 ELF 都进入候选索引，但只有可执行 ELF 默认成为根目标。

根目标识别是静态判定：`ET_EXEC` 是程序候选；`ET_DYN` 需要结合 PIE 标记、解释器和入口信息判断。文件名只能提供线索，不能单独决定类型。无法明确分类的 ELF 保留为不确定组件，不静默丢弃，也不强行建组。

符号链接需要保留别名和实际目标；循环或断开的链接记录原因。指向允许范围之外的文件不能自动引入。sysroot 内的目标系统绝对路径按 sysroot 映射，不访问宿主机同名路径。

## 依赖匹配

首期以 `DT_NEEDED` 为依赖边的依据。导入符号和版本信息辅助检查候选，不据此把无关库自动加入分析组。

每条声明按以下步骤解析：

1. 根据声明名称查找文件名、链接别名和 `SONAME` 候选。
2. 检查架构、位数、端序，以及可读取的 ABI 和所需符号版本信息。
3. 若有可解析的声明路径或 `RPATH`、`RUNPATH`、`$ORIGIN`，在允许范围内使用路径信息缩小候选范围。
4. 候选唯一且没有已知不兼容时建立依赖边；仍有多个不同候选则记录冲突，不按扫描顺序选第一个。

缺少 `SONAME` 不直接判失败；仅有相同架构也不足以证明运行时兼容。无法验证的信息要保留在结果中。

第一版采用静态候选解析，不完整模拟目标动态加载器。工作根目录和显式依赖目录是解析范围，宿主机缓存和环境变量不参与解析。路径选中的文件若不兼容，应报告原因，不能偷偷换成别处的库并声称还原了加载行为。

## 分组与输出

每个组包含根组件、已解析依赖、依赖边、未解析记录及组状态。组件记录文件哈希、来源路径、架构和读取结果；依赖边记录声明方、所需名称、候选和选择依据。

相同内容可以共享组件身份和基础分析产物，但保留各来源路径。`$ORIGIN` 和解析上下文按具体路径记录，不能只凭哈希共享依赖解析结果。

| 状态 | 含义 |
| --- | --- |
| `complete` | 本轮支持范围内的声明依赖均已解析 |
| `partial` | 根目标可读取，但存在缺失、冲突、损坏或无法确认的依赖 |
| `invalid` | 根目标无法形成可分析对象 |

`complete` 只说明声明依赖解析完成，不保证运行时加载、调用关系或漏洞分析完整。没有 `DT_NEEDED` 的 ELF 可以形成单成员组，但不能仅凭这一点断言它是静态链接程序。

## 日志与失败

记录搜索范围、识别出的根目标、组件数量、依赖解析结果和处理耗时。失败记录关联组件、依赖名称和原因。一次组件读取失败不能让其他组的结果丢失。

## 验证场景

- 单 ELF 无依赖来源：保留依赖声明，缺失项使组成为 `partial`。
- 单 ELF 没有声明依赖：生成单成员组。
- rootfs 包含普通程序和 PIE：均能成为根候选。
- 两个程序共享一个库：分别建组，引用同一组件。
- 库依赖另一个库：递归加入，循环依赖正常结束。
- 同名库存在不同版本或架构：排除已知不兼容候选，无法唯一确定时记录冲突。
- 链接越界、断开或循环：记录状态，不读取宿主机文件。
- 同内容库位于不同路径：共享内容身份，保留各自的路径解析上下文。

仓库的 `data/simple_demo/` 已包含普通可执行程序、PIE 和共享库，可用于后续验证。具体依赖边以实际解析结果为准。
